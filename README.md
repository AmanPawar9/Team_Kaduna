# Latent Probing for Mental Health Sentiment Classification using Gemma

> **Team: Kaduna**

---

# Project Overview

This project explores whether the internal representations (hidden states) of Google's **Gemma Large Language Model (LLM)** contain enough information to classify different mental health sentiments **without fine-tuning the entire model**.

Instead of training a new large model, we will:

1. Load a pretrained Gemma model.
2. Extract hidden representations from different transformer layers.
3. Convert these hidden representations into sentence embeddings.
4. Train simple machine learning classifiers (called **linear probes**) on these embeddings.
5. Compare which layers contain the most useful mental health information.

The primary goal is to **understand the representations learned by Gemma**, not to build the most accurate classifier possible.

---

# Project Goal

Our project aims to answer the following research question:

> **Can simple machine learning models accurately classify mental health sentiment using only the hidden representations generated by Gemma?**

We also want to investigate:

- Which transformer layers contain the most useful information?
- Which pooling strategy works best?
- How well do simple classifiers perform?
- Can we avoid fine-tuning the complete LLM?
