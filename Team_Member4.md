# What is a Linear Probe?

A Linear Probe is simply a classifier trained on fixed embeddings.

Instead of

```
Text

↓

Train Gemma
```

we do

```
Text

↓

Gemma (Frozen)

↓

Embedding

↓

Train Classifier
```

This helps us measure how informative the embeddings are.
